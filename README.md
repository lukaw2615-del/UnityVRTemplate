# Spooky VR Template: Halloween Update

A clean Unity VR starter project with a Halloween twist. This version is themed for a spooky haunted VR experience and is ready for a Quest/Android APK build.

## What this includes
- XR rig / player setup for VR
- Simple haunted map scene
- Spooky lighting and atmosphere
- Android/Quest build configuration
- GitHub Actions workflow for APK export
- Ready for Halloween-themed gameplay expansion

## Project goal
This template is meant to be a base for a haunted VR game or a spooky fan game experience. You can swap in your own player model, add lanterns, fog, graveyard props, and create a scary environment.

## Setup
1. Open in Unity 2022.3 LTS or another supported VR version.
2. Import XR Interaction Toolkit / OpenXR packages if needed.
3. Build for Android with ARM64 enabled.
4. Install to a Quest or Android VR headset with adb or SideQuest.
